# =============================================================================
# External Tools Required (not Python packages)
# =============================================================================
#
# These must be installed separately and available in PATH:
#
# 1. FastQC (https://www.bioinformatics.babraham.ac.uk/projects/fastqc/)
#    - Quality control for sequencing data
#
# 2. fastp (https://github.com/OpenGene/fastp)
#    - Fast adapter trimming and quality filtering
#
# 3. HISAT2 (http://daehwankimlab.github.io/hisat2/)
#    - Fast and sensitive alignment program
#
# 4. SAMtools (http://www.htslib.org/)
#    - Tools for manipulating alignment files
#
# 5. BCFtools (http://www.htslib.org/)
#    - Tools for manipulating VCF files
#
# 6. GATK (https://gatk.broadinstitute.org/)
#    - Genome Analysis Toolkit for variant calling
#
# 7. PLINK (https://www.cog-genomics.org/plink/2.0/)
#    - Whole genome association analysis toolset
#
# 8. BEDtools (https://bedtools.readthedocs.io/)
#    - Toolset for genome arithmetic
#
